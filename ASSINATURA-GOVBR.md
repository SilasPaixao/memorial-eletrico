# Fluxo de assinatura GOV.BR

1. Gerar o PDF em rascunho.
2. Abrir https://assinador.iti.br/ e assinar individualmente cada PDF.
3. Salvar os PDFs assinados em local seguro.
4. Importar cada PDF no aplicativo para registrar nome, tamanho, data e hash SHA-256.

**Atenção:** o aplicativo não verifica certificados, assinaturas PAdES nem a validade dos documentos. O registro local de importação não constitui comprovação de assinatura. O arquivo PDF assinado original deve ser preservado. A imagem CRT/CFT é identificação profissional, não assinatura.
